# MADAR (مدار)
Your Life. Your Choices. Your Legacy. / حياتك. اختياراتك. إرثك.

## Run
`npm install && npm run dev` — or push to GitHub (branch `main`) and enable Settings > Pages > Source: GitHub Actions; the workflow builds and publishes it.
